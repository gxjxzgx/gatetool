OpenVPN 节点 ovpn

「住宅 / 数据中心」按 VPN Gate 主机名前缀估算（vpn+数字→住宅，public-vpn→机房），非严格判定。住宅节点 > 20 个时，机房节点只在此页显示，不写入订阅；列表按 住宅 → 机房 → 未识别 排序。

SSTP 节点检测 sstp

全部 住宅 IP 数据中心 未识别
节点来自 VPN Gate（仅 TCP 入口中继），先由检测服务判定可用；「vless 延迟」是转换成 vless 后经 edgetunnel 链式代理实测的往返耗时（TLS + WebSocket + 访问 generate_204），测速失败时这一列显示失败原因（如 WS 403、链路断开、链路超时）。「住宅 / 数据中心」为基于出口信息的估算。点击 host:port 复制 sstp 链接。住宅节点 > 20 个时，机房节点只在此页显示，不写入订阅/清单；列表按 住宅 → 机房 → 未识别 排序。
